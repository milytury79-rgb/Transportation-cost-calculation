
# 🚌 스마트 교통비 계산 프로그램

## 1. 프로젝트 소개
학생들이 학교에 등교하거나 학원에 갈 때 사용하는 대중교통 비용을 쉽게 계산하고 관리할 수 있도록 제작한 웹 프로그램입니다.

교통수단, 1회 이용 요금, 하루 이용 횟수, 한 달 이용 일수 등을 입력하면 예상 교통비를 자동으로 계산해 줍니다.

## 2. 개발 목적
매일 발생하는 교통비를 쉽게 파악하여 학생들이 용돈과 생활비를 효율적으로 관리할 수 있도록 돕는 것을 목적으로 합니다.

## 3. 주요 기능

- 교통수단 선택 기능
  - 버스
  - 지하철
  - 기타 교통수단

- 이용 요금 입력 기능
  - 1회 이용 요금 입력
  - 잘못된 금액 입력 방지

- 이용 횟수 및 날짜 입력 기능
  - 하루 이용 횟수 입력
  - 한 달 이용 일수 입력

- 할인 적용 기능
  - 할인 적용 여부 선택
  - 할인율 설정

- 교통비 계산 기능
  - 총 이용 횟수 계산
  - 할인 전 교통비 계산
  - 할인 금액 계산
  - 할인 후 최종 교통비 계산

- 결과 출력 기능
  - 할인 전 교통비
  - 할인 금액
  - 할인 후 교통비
  - 하루 평균 교통비
  - 한 달 예상 교통비

- 다시 계산하기 기능

## 6. 실행 방법

1. Python을 설치합니다.
2. Streamlit 라이브러리를 설치합니다.

```bash
pip install streamlit
```

3. 프로그램을 실행합니다.

```bash
streamlit run app.py
```

## 7. 교통비 계산 공식

총 이용 횟수 = 하루 이용 횟수 × 한 달 이용 일수

할인 전 교통비 = 1회 이용 요금 × 총 이용 횟수

할인 금액 = 할인 전 교통비 × 할인율 ÷ 100

최종 교통비 = 할인 전 교통비 - 할인 금액

하루 평균 교통비 = 최종 교통비 ÷ 한 달 이용 일수

## 8. 기대 효과

- 자신의 교통비 지출을 쉽게 확인할 수 있습니다.
- 한 달 동안 필요한 교통비를 미리 예상할 수 있습니다.
- 할인 적용에 따른 교통비 차이를 비교할 수 있습니다.
- 계획적인 용돈 및 생활비 관리에 도움을 줍니다.

## 9. 제작 목적

학생들의 합리적인 소비 습관 형성과 효율적인 교통비 관리를 위한 프로그램입니다.
